# La langue copte : règles et sens des mots

> Comprendre ce que tu lis et entends à l'église : les lettres et les signes, les articles et les petits mots, les verbes, puis le sens mot à mot des formules de la Trinité, de la Vierge, des saints et de la messe. Aucun par-cœur : il s'agit de savoir découper un mot pour le comprendre.

## Le copte, langue des pharaons
%% l1501

Le **copte** est la **dernière étape de la langue des pharaons**, l'égyptien ancien, qui s'écrivait autrefois en hiéroglyphes. À partir des premiers siècles chrétiens, on l'écrit avec l'**alphabet grec**, auquel on a **ajouté quelques lettres** pour les sons égyptiens que le grec n'avait pas :

- **ϣ** (shai) : le son « ch » ;
- **ϥ** (fai) : « f » ;
- **ϧ** (khai) : « kh », comme la jota espagnole ;
- **ϩ** (hori) : « h » ;
- **ϫ** (janja) : « dj » ;
- **ϭ** (tchima) : « tch » ;
- **ϯ** (ti) : « ti ».

Une astuce : **si un mot contient une de ces lettres spéciales, il est égyptien** (et non grec).

Le copte avait plusieurs dialectes. La **liturgie** copte est en **bohaïrique**, le dialecte du **Nord** (du delta et d'Alexandrie, et des monastères du Wadi Natroun).

Après la conquête arabe de l'Égypte, en **641**, l'arabe remplace peu à peu le copte dans la vie de tous les jours. Mais l'**Église garde le copte pour la prière** : c'est sa langue sacrée, celle des Pères et des martyrs.

!! Le copte : la dernière étape de la langue des pharaons, écrite avec l'alphabet grec plus des lettres égyptiennes (ϣ, ϥ, ϧ, ϩ, ϫ, ϭ, ϯ). Une lettre spéciale : le mot est égyptien. La liturgie est en bohaïrique (le Nord). Depuis 641, l'Église garde le copte pour prier.

## Les mots grecs que tu connais déjà
%% l1502

Beaucoup de **mots religieux** du copte sont **grecs**, et le français les a gardés aussi :

- **ⲁⲅⲅⲉⲗⲟⲥ** (angelos) = **ange**, « messager » ;
- **ⲉⲩⲁⲅⲅⲉⲗⲓⲟⲛ** (evangelion) = **évangile**, « bonne nouvelle » ;
- **ⲉⲕⲕⲗⲏⲥⲓⲁ** (ekklisia) = **église**, « assemblée » ;
- **ⲡⲁⲣⲑⲉⲛⲟⲥ** (parthenos) = **vierge** ;
- **ⲁ̀ⲡⲟⲥⲧⲟⲗⲟⲥ** (apostolos) = **apôtre**, « envoyé » ;
- **ⲙⲁⲣⲧⲩⲣⲟⲥ** (martyros) = **martyr**, « témoin ».

Attention : un mot **sans** lettre spéciale peut être **grec ou égyptien**. Seule la présence d'une lettre spéciale te donne une certitude.

!! Beaucoup de mots religieux coptes sont grecs : ⲁⲅⲅⲉⲗⲟⲥ (ange, messager), ⲉⲩⲁⲅⲅⲉⲗⲓⲟⲛ (évangile, bonne nouvelle), ⲉⲕⲕⲗⲏⲥⲓⲁ (assemblée, église), ⲡⲁⲣⲑⲉⲛⲟⲥ (vierge).

## La jinkim : le petit trait qui se lit
%% l1503

La **jinkim** est un **petit trait** (ou un point) posé **au-dessus d'une lettre**. Elle **ne change pas le sens** du mot : elle te dit **comment le lire**.

- Sur une **consonne** : on lit un petit « **e** » **devant** elle. Exemple : **ⲙ̀** se lit « em », **ⲫ̀** se lit « ef ».
- Sur une **voyelle** : la voyelle se lit **à part**, comme une syllabe seule.
- Dans un mot grec qui commence par **deux consonnes** de suite, la jinkim ajoute un petit « e » pour faciliter la prononciation : **ⲡ̀ⲛⲉⲩⲙⲁ** se lit « epnevma ».

Avec ou sans jinkim, **c'est le même mot**.

!! La jinkim ne change pas le sens : elle guide la lecture. Sur une consonne : un petit « e » devant (ⲙ̀ = « em »). Sur une voyelle : elle se lit à part.

## Les noms sacrés abrégés
%% l1504

Ne confonds pas deux signes :

- la **jinkim** porte sur **une seule lettre** ;
- le **surlignage** (une barre au-dessus de **plusieurs lettres**) signale un **mot abrégé**.

Les **noms sacrés** sont abrégés **par respect**, depuis le **IIe siècle** : on garde le **début** et la **fin** du mot, et on trace une barre dessus.

- **ⲓ̅ⲏ̅ⲥ̅** = **Jésus** (Iisous), un nom qui veut dire « **Dieu sauve** » ;
- **ⲭ̅ⲥ̅** = le **Christ** (Khristos), « **l'oint** » ;
- **ⲡ̅ⲟ̅ⲥ̅** = le **Seigneur** (Pchois) ;
- **ⲫ̅ϯ̅** = **Dieu** (Efnouti).

!! Jinkim : une lettre. Surlignage : plusieurs lettres, un mot abrégé. ⲓ̅ⲏ̅ⲥ̅ = Jésus (« Dieu sauve ») ; ⲭ̅ⲥ̅ = le Christ (« l'oint ») ; ⲡ̅ⲟ̅ⲥ̅ = le Seigneur ; ⲫ̅ϯ̅ = Dieu. Par respect, depuis le IIe siècle.

## Les articles : le, la, les, un
%% l1505

Pour comprendre un mot copte, la première règle est : **détache l'article, puis cherche le nom**. L'article est collé **devant** le nom.

- **ⲡⲓ** (pi) = **le** (masculin) ; forme courte **ⲡ̀** ou **ⲫ̀** ;
- **ϯ** (ti) = **la** (féminin) ; forme courte **ⲧ̀** ou **ⲑ̀** ;
- **ⲛⲓ** (ni) = **les** ;
- **ⲟⲩ** (ou) = **un, une** ;
- **ϩⲁⲛ** (han) = **des**.

Le **genre** se lit sur l'**article**, pas sur la fin du mot.

Le piège de **ⲫ̀** : **Ⲫ̀ⲛⲟⲩϯ** (Efnouti) = **ⲫ̀** (le) + **ⲛⲟⲩϯ** (dieu) = « **le Dieu** », c'est-à-dire **Dieu**, le seul vrai Dieu. Et **ⲟⲩⲛⲟⲩϯ** = « **un** dieu ».

!! Détache l'article, puis cherche le nom. ⲡⲓ = le ; ϯ = la ; ⲛⲓ = les ; ⲟⲩ = un, une ; ϩⲁⲛ = des. Le genre se lit sur l'article. Ⲫ̀ⲛⲟⲩϯ = ⲫ̀ (le) + ⲛⲟⲩϯ : Dieu.

## Mon, ton, notre : les possessifs
%% l1506

Le **possessif remplace l'article** : on ne dit pas « le mon Dieu », mais directement **ⲡⲁⲛⲟⲩϯ**, « **mon Dieu** ».

Le possessif se construit en deux morceaux : une lettre qui s'accorde avec la **chose possédée** (**ⲡ-** masculin, **ⲧ-** féminin, **ⲛ-** pluriel), puis une marque pour le **possesseur** :

- **ⲡⲁ-** = mon ;
- **ⲡⲉⲕ-** = ton ;
- **ⲡⲉϥ-** = son (à lui) ; **ⲡⲉⲥ-** = son (à elle) ;
- **ⲡⲉⲛ-** = notre ;
- **ⲡⲉⲧⲉⲛ-** = votre ;
- **ⲡⲟⲩ-** = leur.

Les petites marques des personnes reviennent partout : **ⲕ** = toi, **ϥ** = lui, **ⲥ** = elle, **ⲛ** = nous, **ⲧⲉⲛ** = vous, **ⲟⲩ** = eux.

Exemples : **Ⲡⲉⲛⲓⲱⲧ** = ⲡⲉⲛ- (notre) + ⲓⲱⲧ (père) = « **notre Père** », le début du Notre Père. **ⲡⲉⲕⲣⲁⲛ** = « **ton nom** » (« que ton nom soit sanctifié »).

!! Le possessif remplace l'article : ⲡⲁⲛⲟⲩϯ = mon Dieu. ⲡⲁ- = mon, ⲡⲉⲕ- = ton, ⲡⲉϥ- = son, ⲡⲉⲛ- = notre. Ⲡⲉⲛⲓⲱⲧ = notre Père. ⲡ- masculin, ⲧ- féminin, ⲛ- pluriel, selon la chose possédée.

## Les petits mots : et, dans, de, saint
%% l1507

Quatre petits mots structurent presque chaque phrase :

- **ⲛⲉⲙ** (nem) = **et**, **avec** ;
- **ϧⲉⲛ** (khen) = **dans**, **en** ;
- **ⲛ̀** (en) = **de** ; il devient **ⲙ̀** (em) devant **ⲡ, ⲫ, ⲃ, ⲙ** (comme en français « en » devient « em » devant p et b) ;
- **ⲉⲑⲟⲩⲁⲃ** (ethouab) = **saint** ; il se place **après** le nom.

Exemple : **ϧⲉⲛ ⲫ̀ⲣⲁⲛ ⲙ̀Ⲫ̀ⲓⲱⲧ** = ϧⲉⲛ (dans) + ⲫ̀ⲣⲁⲛ (le nom) + ⲙ̀ (de) + Ⲫ̀ⲓⲱⲧ (le Père) = « **dans le nom du Père** ».

!! ⲛⲉⲙ = et, avec ; ϧⲉⲛ = dans ; ⲛ̀ = de (ⲙ̀ devant ⲡ, ⲫ, ⲃ, ⲙ) ; ⲉⲑⲟⲩⲁⲃ = saint, après le nom. ϧⲉⲛ ⲫ̀ⲣⲁⲛ ⲙ̀Ⲫ̀ⲓⲱⲧ = dans le nom du Père.

## « Il est ressuscité » : le passé
%% l1508

Le **passé** se forme avec **ⲁ** suivi de la marque de la personne, puis du verbe :

- **ⲁϥ-** = il a… ;
- **ⲁⲥ-** = elle a… ;
- **ⲁⲩ-** = ils ont….

Le cri de Pâques : **ⲁϥⲧⲱⲛϥ** = ⲁ (passé) + ϥ (il) + ⲧⲱⲛ (se lever) + ϥ (lui-même) = « **il s'est levé** », c'est-à-dire « **il est ressuscité** ».

» Ⲭ̀ⲣⲓⲥⲧⲟⲥ ⲁϥⲧⲱⲛϥ ! — Ⲁ̀ⲗⲏⲑⲱⲥ ⲁϥⲧⲱⲛϥ ! « Le Christ est ressuscité ! — Il est vraiment ressuscité ! »

Remarque : ce sont **les mêmes marques** (ϥ = il, ⲥ = elle, ⲟⲩ = ils) pour le possessif (« son ») et pour le verbe (« il »).

!! ⲁ = passé : ⲁϥ- = il a, ⲁⲥ- = elle a, ⲁⲩ- = ils ont. ⲁϥⲧⲱⲛϥ = il s'est levé = il est ressuscité. Ⲭ̀ⲣⲓⲥⲧⲟⲥ ⲁϥⲧⲱⲛϥ ! — Ⲁ̀ⲗⲏⲑⲱⲥ ⲁϥⲧⲱⲛϥ !

## « Je crois », « bénis » : le présent et l'ordre
%% l1509

- **ϯ-** devant un verbe veut dire **je** (au présent) : **ϯⲛⲁϩϯ** = ϯ (je) + ⲛⲁϩϯ (croire) = « **je crois** ».
- **Ϯⲛⲁϩϯ ϧⲉⲛ ⲟⲩⲛⲟⲩϯ** = « je crois en un Dieu » : les premiers mots du Credo dans sa forme personnelle.
- Le **verbe seul**, sans rien devant, donne un **ordre** : **ⲥⲙⲟⲩ** = « **bénis !** » (comme dans « Seigneur, bénis »).

Retiens : **ⲁ** = passé ; **ϯ** = je ; **rien** = ordre.

!! ϯ + verbe = je : ϯⲛⲁϩϯ = je crois. Le verbe seul donne l'ordre : ⲥⲙⲟⲩ = bénis ! ⲁ = passé ; ϯ = je ; rien = ordre.

## Père, Fils, Esprit : le signe de croix
%% l1510

Les trois noms divins, décortiqués :

- **Ⲫ̀ⲓⲱⲧ** (efiot) = ⲫ̀ (le) + ⲓⲱⲧ (père) = **le Père** ;
- **Ⲡ̀ϣⲏⲣⲓ** (epshiri) = ⲡ̀ (le) + ϣⲏⲣⲓ (fils) = **le Fils** ;
- **Ⲡⲓⲡ̀ⲛⲉⲩⲙⲁ ⲉⲑⲟⲩⲁⲃ** (pipnevma ethouab) = ⲡⲓ (le) + ⲡ̀ⲛⲉⲩⲙⲁ (esprit, du grec pneuma, « **souffle** ») + ⲉⲑⲟⲩⲁⲃ (saint) = **le Saint-Esprit**.

La formule du signe de croix :

» ϧⲉⲛ ⲫ̀ⲣⲁⲛ ⲙ̀Ⲫ̀ⲓⲱⲧ ⲛⲉⲙ Ⲡ̀ϣⲏⲣⲓ ⲛⲉⲙ Ⲡⲓⲡ̀ⲛⲉⲩⲙⲁ ⲉⲑⲟⲩⲁⲃ, ⲟⲩⲛⲟⲩϯ ⲛ̀ⲟⲩⲱⲧ. Ⲁ̀ⲙⲏⲛ.

Mot à mot : **dans** (ϧⲉⲛ) **le nom** (ⲫ̀ⲣⲁⲛ) **du Père** (ⲙ̀Ⲫ̀ⲓⲱⲧ) **et du Fils** (ⲛⲉⲙ Ⲡ̀ϣⲏⲣⲓ) **et du Saint-Esprit** (ⲛⲉⲙ Ⲡⲓⲡ̀ⲛⲉⲩⲙⲁ ⲉⲑⲟⲩⲁⲃ), **un seul Dieu** (ⲟⲩⲛⲟⲩϯ ⲛ̀ⲟⲩⲱⲧ). **Amen.**

Remarque : **ⲫ̀ⲣⲁⲛ**, « le nom », est au **singulier** : **un seul nom, trois personnes**. C'est la Trinité dans la grammaire.

!! Ⲫ̀ⲓⲱⲧ = le Père ; Ⲡ̀ϣⲏⲣⲓ = le Fils ; Ⲡⲓⲡ̀ⲛⲉⲩⲙⲁ ⲉⲑⲟⲩⲁⲃ = le Saint-Esprit (pneuma = souffle). ⲫ̀ⲣⲁⲛ est au singulier : un seul nom, trois personnes.

## Trinité, roi, Tout-Puissant, Sauveur
%% l1511

Quatre titres de Dieu que tu entends dans les hymnes :

- **ϯⲧ̀ⲣⲓⲁⲥ** (ti-trias) = **la Trinité** ; du grec trias, « groupe de trois » ;
- **ⲟⲩⲣⲟ** (ouro) = **roi** ; **ⲡⲓⲟⲩⲣⲟ** = le roi ; c'est un mot **égyptien** ;
- **Ⲡⲓⲡⲁⲛⲧⲟⲕⲣⲁⲧⲱⲣ** (pipantokrator) = **le Tout-Puissant**, « celui qui tient tout » (comme dans le Credo) ;
- **Ⲡⲉⲛⲥⲱⲧⲏⲣ** (pensotir) = ⲡⲉⲛ- (notre) + ⲥⲱⲧⲏⲣ (sauveur, grec sôtêr) = **notre Sauveur**.

Trinité, Tout-Puissant et Sauveur sont **grecs** ; roi est **égyptien**.

!! ϯⲧ̀ⲣⲓⲁⲥ = la Trinité (grec trias). ⲟⲩⲣⲟ = roi (égyptien). Ⲡⲓⲡⲁⲛⲧⲟⲕⲣⲁⲧⲱⲣ = le Tout-Puissant. Ⲡⲉⲛⲥⲱⲧⲏⲣ = notre Sauveur.

## La Vierge Marie : titres et salut
%% l1512

- **ϯⲡⲁⲣⲑⲉⲛⲟⲥ Ⲙⲁⲣⲓⲁ** = ϯ (la) + ⲡⲁⲣⲑⲉⲛⲟⲥ (vierge) + Marie = **la Vierge Marie** ;
- **ϯⲑⲉⲟⲧⲟⲕⲟⲥ** = ϯ (la) + ⲑⲉⲟⲥ (Dieu) + ⲧⲟⲕⲟⲥ (enfantement) = **la Mère de Dieu**, « celle qui enfante Dieu » ; ce titre a été proclamé à **Éphèse en 431** ;
- **ⲭⲉⲣⲉ ⲛⲉ ⲱ̀ Ⲙⲁⲣⲓⲁ** = « **salut à toi, ô Marie** » (ⲭⲉⲣⲉ, grec khaire, « réjouis-toi », la salutation de l'ange) ;
- **ϯⲑⲉⲟⲧⲟⲕⲟⲥ ⲉⲑⲟⲩⲁⲃ Ⲙⲁⲣⲓⲁ** = « **la sainte Mère de Dieu, Marie** ».

!! ϯⲡⲁⲣⲑⲉⲛⲟⲥ Ⲙⲁⲣⲓⲁ = la Vierge Marie. ϯⲑⲉⲟⲧⲟⲕⲟⲥ = ⲑⲉⲟⲥ (Dieu) + ⲧⲟⲕⲟⲥ (enfantement) : la Mère de Dieu (Éphèse, 431). ⲭⲉⲣⲉ ⲛⲉ ⲱ̀ Ⲙⲁⲣⲓⲁ = salut à toi, ô Marie.

## Les saints et leurs intercessions
%% l1513

- **ⲛⲓⲁ̀ⲡⲟⲥⲧⲟⲗⲟⲥ** = ⲛⲓ (les) + ⲁ̀ⲡⲟⲥⲧⲟⲗⲟⲥ (envoyé) = **les apôtres** ;
- **ⲙⲁⲣⲧⲩⲣⲟⲥ** = **martyr**, « témoin » ;
- **ⲁ̀ⲅⲓⲟⲥ** (grec) et **ⲉⲑⲟⲩⲁⲃ** (copte) veulent **tous deux** dire **saint** ;
- **ⲛⲓⲡ̀ⲣⲉⲥⲃⲓⲁ** (ni-epresvia) = **les intercessions** ;
- **ϩⲓⲧⲉⲛ** (hiten) = **par** (le moyen de) ; à distinguer de **ϧⲉⲛ**, **dans** (le lieu).

La formule qu'on entend à chaque office :

» Ϩⲓⲧⲉⲛ ⲛⲓⲡ̀ⲣⲉⲥⲃⲓⲁ ⲛ̀ϯⲑⲉⲟⲧⲟⲕⲟⲥ ⲉⲑⲟⲩⲁⲃ Ⲙⲁⲣⲓⲁ…

Mot à mot : **par** (ϩⲓⲧⲉⲛ) **les intercessions** (ⲛⲓⲡ̀ⲣⲉⲥⲃⲓⲁ) **de la** (ⲛ̀ϯ) **Mère de Dieu** (ⲑⲉⲟⲧⲟⲕⲟⲥ) **sainte** (ⲉⲑⲟⲩⲁⲃ) **Marie**… et la suite : « Seigneur, accorde-nous le pardon de nos péchés ».

!! ⲛⲓⲁ̀ⲡⲟⲥⲧⲟⲗⲟⲥ = les apôtres ; ⲙⲁⲣⲧⲩⲣⲟⲥ = martyr (témoin) ; ⲁ̀ⲅⲓⲟⲥ et ⲉⲑⲟⲩⲁⲃ = saint ; ⲛⲓⲡ̀ⲣⲉⲥⲃⲓⲁ = les intercessions ; ϩⲓⲧⲉⲛ = par, ϧⲉⲛ = dans.

## Amen, alléluia, la paix à tous
%% l1514

Les réponses de la messe viennent de **trois langues** : l'**hébreu**, le **grec** et le **copte**.

- **ⲁ̀ⲙⲏⲛ** (amin), **hébreu** = « **c'est vrai** », « ainsi soit-il » ;
- **ⲁ̀ⲗⲗⲏⲗⲟⲩⲓⲁ** (allilouia), **hébreu** = « **louez Dieu** » (Hallelou-Yah) ;
- **ϣⲁ ⲉ̀ⲛⲉϩ** (sha eneh), **copte** = « **pour toujours** », « jusqu'à l'éternité » ;
- **Ⲓ̀ⲣⲏⲛⲏ ⲡⲁⲥⲓ** (irini pasi), **grec** = « **la paix à tous** » ; l'assemblée répond « et à ton esprit ».

!! Amen (hébreu) = c'est vrai ; alléluia (hébreu) = louez Dieu ; ϣⲁ ⲉ̀ⲛⲉϩ (copte) = pour toujours ; Ⲓ̀ⲣⲏⲛⲏ ⲡⲁⲥⲓ (grec) = la paix à tous.

## Aie pitié, gloire à toi : grec ou copte
%% l1515

La même prière se dit souvent en **deux langues** :

- **Pitié** : **Ⲕⲩⲣⲓⲉ ⲉ̀ⲗⲉⲏ̀ⲥⲟⲛ** (Kyrie eleison), en **grec** = « Seigneur, aie pitié » ; **ⲛⲁⲓ ⲛⲁⲛ** (nai nan), en **copte** = « pitié à nous », c'est-à-dire « aie pitié de nous ».
- **Gloire** : **Ⲇⲟⲝⲁ ⲥⲓ Ⲕⲩⲣⲓⲉ** (Doxa si Kyrie), en **grec** = « gloire à toi, Seigneur » ; **ⲡⲓⲱⲟⲩ** (pi-ô-ou), en **copte** = « la gloire » (ⲇⲟⲝⲁ en grec).

!! Pitié : Ⲕⲩⲣⲓⲉ ⲉ̀ⲗⲉⲏ̀ⲥⲟⲛ (grec) ou ⲛⲁⲓ ⲛⲁⲛ (copte). Gloire : ⲇⲟⲝⲁ (grec) ou ⲡⲓⲱⲟⲩ (copte). Ⲇⲟⲝⲁ ⲥⲓ Ⲕⲩⲣⲓⲉ = gloire à toi, Seigneur.

## Le copte caché dans l'arabe d'Égypte
%% l1516

L'**arabe d'Égypte** a gardé des **mots coptes**, souvent sans qu'on le sache :

- **طوب** (toub, la **brique**) vient de **ⲧⲱⲃⲉ** ;
- **واحة** (waha, l'**oasis**) vient de **ⲟⲩⲁϩⲉ** ;
- **تمساح** (timsah, le **crocodile**) vient de **ⲉⲙⲥⲁϩ** ;
- **الفيوم** (le **Fayoum**) vient de **ⲫⲓⲟⲙ** = ⲫ (le) + ⲓⲟⲙ (mer, lac) : « **le lac** ».

Attention : **طوب** (la brique) et **طوبة** (Touba, le mois copte) se ressemblent par le son, mais ce sont **deux mots** différents.

!! L'arabe d'Égypte garde des mots coptes : طوب (brique) ← ⲧⲱⲃⲉ ; واحة (oasis) ← ⲟⲩⲁϩⲉ ; تمساح (crocodile) ← ⲉⲙⲥⲁϩ ; الفيوم ← ⲫⲓⲟⲙ, « le lac ».

## Shenouda, Bishoy, Tawadros : des prénoms à lire
%% l1517

Derrière beaucoup de prénoms coptes se cache un mot copte ou grec :

- **أنبا** (Anba) ← **ⲁⲃⲁ** (abba) : « **père** », titre des évêques et des saints moines ;
- **شنودة** (Chenouda) ← **Ϣⲉⲛⲟⲩϯ** : « **enfant de Dieu** » (ϣⲉ, enfant + ⲛⲟⲩϯ, Dieu) ;
- **بيشوي** (Bishoy) ← **Ⲡⲓϣⲱⲓ** : « **le haut** », « l'élevé » (ⲡⲓ, le + ϣⲱⲓ, haut) ;
- **تاوضروس** (Tawadros) ← **ⲑⲉⲟⲇⲱⲣⲟⲥ** (grec Théodoros) : « **don de Dieu** » (theos, Dieu + dôron, don).

!! أنبا ← ⲁⲃⲁ : « père ». شنودة ← Ϣⲉⲛⲟⲩϯ : « enfant de Dieu ». بيشوي ← Ⲡⲓϣⲱⲓ : « le haut ». تاوضروس ← ⲑⲉⲟⲇⲱⲣⲟⲥ : « don de Dieu » (grec).

## Bilan : lire et comprendre une formule copte
%% l1518

### La méthode en quatre gestes
- **Détache** l'article ou le possessif (ⲡⲓ, ϯ, ⲛⲓ, ⲟⲩ, ⲡⲉⲛ-…).
- **Repère** la jinkim et les lettres spéciales (pour lire, et pour savoir si le mot est égyptien).
- **Cherche** le nom ou le verbe (ⲁ- passé, ϯ- je, rien = ordre).
- **Lis** les petits mots (ⲛⲉⲙ, ϧⲉⲛ, ⲛ̀/ⲙ̀, ⲉⲑⲟⲩⲁⲃ, ϩⲓⲧⲉⲛ).

### La langue d'un mot aide à deviner son sens
**Égyptien** (lettres spéciales : ⲟⲩⲣⲟ, ϣⲏⲣⲓ, ⲛⲟⲩϯ), **grec** (ⲁⲅⲅⲉⲗⲟⲥ, ⲡⲁⲣⲑⲉⲛⲟⲥ, ⲥⲱⲧⲏⲣ), **hébreu** (ⲁ̀ⲙⲏⲛ, ⲁ̀ⲗⲗⲏⲗⲟⲩⲓⲁ).

### La formule à savoir découper
ϧⲉⲛ ⲫ̀ⲣⲁⲛ ⲙ̀Ⲫ̀ⲓⲱⲧ ⲛⲉⲙ Ⲡ̀ϣⲏⲣⲓ ⲛⲉⲙ Ⲡⲓⲡ̀ⲛⲉⲩⲙⲁ ⲉⲑⲟⲩⲁⲃ : **dans le nom du Père, et du Fils, et du Saint-Esprit** ; **un seul nom**.

Tu peux maintenant **découper et comprendre** les formules que tu entends à l'église.

? Que veut dire ⲁϥⲧⲱⲛϥ ? | « Il s'est levé », c'est-à-dire « il est ressuscité » : ⲁ (passé) + ϥ (il) + ⲧⲱⲛ (se lever) + ϥ.
? Comment dit-on « notre Père » en copte ? | Ⲡⲉⲛⲓⲱⲧ : ⲡⲉⲛ- (notre) + ⲓⲱⲧ (père).
? Que veut dire ϯⲑⲉⲟⲧⲟⲕⲟⲥ, mot à mot ? | ϯ (la) + ⲑⲉⲟⲥ (Dieu) + ⲧⲟⲕⲟⲥ (enfantement) : la Mère de Dieu.
